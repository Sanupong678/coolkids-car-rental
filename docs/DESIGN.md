# Design — หน้าเว็บลูกค้า (อ้างอิงจากภาพตัวอย่าง 4 ภาพ)

## แนวทางรวม

เราใช้โทนมืดแบบ **ภาพที่ 1 (Mercedes C-Class)** และ **ภาพที่ 4 (หน้าเลือกรถ)** เป็นหลัก ส่วน **ภาพที่ 2 (OVER)** และ **ภาพที่ 3 (GoCars)** ใช้เป็นแหล่งไอเดียเรื่องฟีเจอร์และโครงหน้า

- **สี:** ใช้พื้นเทาดำ (graphite) กับสีเน้นสีเดียวคือ **แชมเปญ/ทอง `#C8A96A`** ไม่ใช้สีแดงแบบภาพที่ 2–3 เพราะดูเป็นเว็บขายรถทั่วไป ภาพที่ 1 และ 4 ให้ความรู้สึกพรีเมียมกว่า สีเปลี่ยนได้จาก CMS (`site.theme`)
- **ตัวอักษร:** หัวข้อใช้ Unbounded (ตัวกว้าง ตัวพิมพ์ใหญ่ ให้ความรู้สึกแบรนด์รถยนต์) เนื้อหาใช้ Inter
- **รายละเอียด:** เส้นบาง (hairline) และขอบมุมแคบ (4–14px) จุด + เส้นเชื่อมหน้าหัวข้อ section ตามภาพที่ 1 และกรอบรูปทรงสี่เหลี่ยมด้านขนาน (เฉียง) ตามภาพที่ 1
- **การเคลื่อนไหว:**
  - หัวข้อ hero ค่อย ๆ ปรากฏทีละคำ ภาพพื้นหลังซูมเข้าช้า ๆ (Ken Burns) และ parallax
  - section ต่าง ๆ ค่อย ๆ ปรากฏเมื่อเลื่อนถึง (`v-reveal`)
  - เมื่อเอาเมาส์วางบนการ์ด รูปจะซูม และมีเส้นทองวิ่งขีดเส้นใต้
  - ถ้าผู้ใช้ตั้งค่า `prefers-reduced-motion` ไว้ การเคลื่อนไหวทั้งหมดจะปิด

## หน้ารายการรถ (`/vehicles`) — ตามภาพที่ 4

- **แถบขั้นตอนด้านบน (sticky):**
  1. วัน-เวลารับ/คืน
  2. สาขารับ
  3. สาขาคืน
  4. รถ
  5. บริการเสริม
  6. ราคารวม

  แต่ละช่องมีเลขขั้นตอนตัวใหญ่สีจางเป็นพื้นหลัง และมีเครื่องหมาย ✓ เมื่อกรอกแล้ว
- **ตัวกรองด้านซ้าย:** ช่วงราคาต่อวัน (checkbox), ประเภทรถ (ไอคอน + จำนวน), เกียร์, เชื้อเพลิง, จำนวนที่นั่ง, ระบบขับ, ยี่ห้อ และปุ่ม "Clear all" บนมือถือตัวกรองจะเป็น drawer เลื่อนออกมา
- **การ์ดรถ:**
  - ชื่อรถ + รุ่นย่อย/ปี และ badge (ประเภทรถ / ชื่อโปรโมชั่น / "Advice of the day")
  - รูปพร้อมแสง spotlight และป้าย −20%
  - **ราคาต่อวันตัวใหญ่** (ราคาเดิมขีดฆ่า) และ **ราคารวมโดยประมาณ** เมื่อเลือกวันแล้ว
  - ชิปสเปก: ที่นั่ง, ประตู, เกียร์, เชื้อเพลิง, แรงม้า/ระยะทาง
- เรียงลำดับได้ 5 แบบ แบ่งหน้าได้ และ **ตัวกรองทั้งหมดเก็บใน URL** จึงแชร์ลิงก์หรือกดปุ่ม back ได้
- **เมื่อเลือกวัน หน้านี้จะแสดงเฉพาะรถที่ว่างจริง** ตรวจจากฐานข้อมูลโดยรวมเวลาเตรียมรถหลังคืน (turnaround) ไม่ได้กรองแค่ใน frontend

## หน้ารายละเอียดรถ (`/vehicles/:slug`)

- **ส่วนหัว:** ภาพรถในกรอบเฉียงแบบภาพที่ 1, ชื่อยี่ห้อ/รุ่นตัวใหญ่, ราคาและโปรโมชั่น, ปุ่ม "Check availability"
- **แถบสเปก:** ไอคอนพร้อมค่า (ที่นั่ง / ประตู / เกียร์ / เชื้อเพลิง / ระบบขับ / แรงม้า)
- **Equipment:** อุปกรณ์จัดกลุ่มตามหมวด SAFETY / INTERIOR / TECHNOLOGY …
- **Technology — Specifications:** ตารางสเปกเส้นบางแบบภาพที่ 1 (เครื่องยนต์, แรงบิด, ขนาดตัวรถ, สัมภาระ, อายุผู้ขับขั้นต่ำ, มัดจำ)
- **ปฏิทินว่าง 2 เดือน:** 🟩 ว่าง 🟥 จองแล้ว 🟧 ซ่อมบำรุง ⬜ ไม่ว่าง
  - เลือกได้เฉพาะช่วงที่ว่างต่อเนื่องกัน
  - แสดงสรุปจำนวนวัน × ราคา (โปรโมชั่นจะใช้เมื่อเช่าครบจำนวนวันขั้นต่ำ)
  - ปุ่มจองจะเปิดใช้ใน Phase 4 (booking engine)
- **รถที่คล้ายกัน:** การ์ดรถในหมวดเดียวกัน

## ข้อมูลและรูปภาพ

- ทุกหน้าดึงข้อมูลจริงจาก API: `/content/*`, `/vehicles`, `/categories`, `/locations`, `/promotions` ไม่มีเนื้อหาธุรกิจ hard-code ใน component
- รูปตัวอย่างมาจาก Unsplash (ใช้ฟรีได้) เก็บเป็นแถว `media` ซึ่งรองรับ responsive `srcset` ตอนใช้งานจริงให้อัปโหลดรูปของบริษัทผ่าน admin media แทน
- ตำแหน่ง hotspot และข้อความใน showcase อยู่ใน `homepage_sections.config` แก้ได้โดยไม่ต้องแก้โค้ด
